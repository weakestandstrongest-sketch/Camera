# 無音カメラ

シャッター音が鳴らない、広告なしの自分用カメラです。
Safari で開くウェブアプリ（PWA）で、ホーム画面に追加すると普通のアプリと同じように使えます。

## なぜ音が鳴らないのか

純正カメラの「撮影」機能は使っていません。カメラの映像をそのまま表示し、シャッターを押した瞬間の 1 コマを画像として切り出しています（無音カメラアプリの多くと同じ仕組みです）。
ビデオも録画開始・終了の音は鳴りません。

## 機能

- 写真（JPEG）／ビデオ（MP4）
- 背面・前面の切り替え。複数レンズがある機種ではレンズを選べます（「レンズ」ボタン）
- ズーム（ピンチ・スライダー）、ライト。iOS が対応している場合だけ表示されます
- グリッド、セルフタイマー（3 秒・10 秒）
- 撮影データは端末の中だけに保存されます。どこにもアップロードされません
- ライブラリでまとめて「保存」すると共有シートが開きます。「画像を保存」または「ビデオを保存」を押すと写真アプリに入ります

## 公開手順（最初の 1 回だけ）

カメラを使うには https のページが必要なので、GitHub Pages で無料公開します。

1. GitHub でこのリポジトリを開き、**Settings → Pages** を開く
2. **Build and deployment** の **Source** を「Deploy from a branch」にする
3. **Branch** で公開したいブランチ（このコードがあるブランチ。`main` にマージした場合は `main`）と `/ (root)` を選び、**Save** を押す
4. 1〜2 分待つと `https://<ユーザー名>.github.io/Camera/` で開けるようになります

## iPhone に入れる

1. 上の URL を **Safari** で開く
2. 共有ボタン →「ホーム画面に追加」
3. ホーム画面のアイコンから起動し、カメラの使用を「許可」する

## 注意点

- 写真の解像度は、カメラ映像の解像度（最大 4K 程度）になります。純正カメラの 4800 万画素や HDR、ナイトモードなどの画像処理は効きません
- 撮影データはアプリ内に一時保存されています。Safari のタブで使っていて 7 日ほど開かないと消されることがあり、ホーム画面から使っていても空き容量が少ないと消される可能性があるので、早めに写真アプリへ保存してください
- 本体を横にして撮るときは、コントロールセンターで画面の縦向きロックを外してください
- 音量ボタンでのシャッターはウェブアプリでは使えません
